# Spinflow

Интерактивный productivity-прототип: задачи становятся секторами колеса, вращение выбирает следующее действие, а после выбора запускается фокус-таймер.

## Что умеет

- добавлять, завершать, возвращать и удалять задачи;
- автоматически перестраивать SVG-колесо;
- случайно выбирать только активные задачи;
- предлагать 15, 25, 45, 60 минут или свою длительность;
- ставить таймер на паузу, продолжать, сбрасывать и завершать сессию;
- сохранять задачи в `localStorage`.

## Локальный запуск

Зависимости для самого приложения не нужны.

```powershell
npm start
```

Или откройте папку любым статическим HTTP-сервером. Прямое открытие `index.html` не рекомендуется из-за ES-модулей.

## Тесты

```powershell
npm test
```

Тесты используют встроенный `node:test` и не требуют установки пакетов.

## Структура

- `index.html` — семантический каркас;
- `src/task-store.js` — задачи и локальное сохранение;
- `src/wheel.js` — SVG-геометрия и выбор сектора;
- `src/timer.js` — чистая логика таймера;
- `src/app.js` — оркестрация интерфейса;
- `src/styles.css` — адаптивная визуальная система;
- `tests/` — модульные тесты.

## GitHub → Vercel

1. Создайте пустой GitHub-репозиторий и добавьте его как `origin`.
2. Отправьте ветку: `git push -u origin master`.
3. В Vercel выберите **Add New → Project** и импортируйте репозиторий.
4. Framework Preset: **Other**. Build Command и Output Directory оставьте пустыми.
5. Нажмите **Deploy**.

Создание GitHub-репозитория и деплой не выполнялись автоматически.
